## 📖 Overview

**Watcher Pro** is a professional-grade Android network security suite built for reconnaissance, diagnostics, and secure config management. It bundles decryption tooling, signal & network mapping, domain intelligence, and SSL/TLS inspection into a single clean, blue-accented interface — available in both **Lite** and **Pro** tiers.

---

## ✨ Features

### 🔓 Decryption Suite
- **Decryptor Tool** — Decrypt VPN/tunnel config files and take full control of your connections.
- **Storage Decryptor** *(Secure File Stream Processor)* — Decrypts local config files with a user-supplied key. Supports `.dark`, `.npvt`, `.hc`, `.ssc`, `.ehi` formats and outputs clean, structured JSON (e.g. VLESS tunnel configs with transport & inject settings) ready to copy or use.

### 📡 Network Tools
- **Signal Mapper** — Map and find networks around you like a pro.
- **Host Checker** — Combined recon: subdomain enumeration, port scanning, and reverse DNS in one pass.

### 🌐 Domain Suite
- **IP Geolocation** — Instantly resolve your IP and location.
- **API Test Hub** — Send requests and inspect API responses on the fly.
- **SSL Check** — View and validate server SSL certificates.
- **TLS Fingerprint** — Inspect server-side TLS details and fingerprinting data.

### 📚 More
- **Public DB** — Additional lookup and reference tooling.
- Live dashboard with active decrypt count, total active sessions, and registered user stats.

## 📦 Installation

1. Download the latest APK release.
2. Enable **Install from unknown sources** on your Android device.
3. Install and launch Watcher Pro.
4. Sign in to unlock Pro features, or continue on Lite.
